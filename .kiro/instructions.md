# Instruções do Projeto

## Stack
- .NET 8

## Estrutura
- Criar um arquivo **Solution (.sln)** na raiz do projeto.
- Criar um projeto de **Web API** usando .NET 8 e adicioná-lo à solution.

## Swagger
- Adicionar o **Swagger (Swashbuckle)** para documentação da API.

## Endpoint de Teste
- Criar um endpoint GET que retorna `true`.

## Projeto de Testes
- Criar um projeto de **testes** e adicioná-lo à solution.
- Criar um teste que verifica se o retorno do endpoint de teste é `true`.
